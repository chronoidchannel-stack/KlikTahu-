# Petir Short v3 — integrated procedural visual

This rebuild replaces the paper header, floating labels and isolated graphic callouts with one continuous rain-soaked city environment. Cloud volume, landmark, neighboring façades, wet pavement, doorway, tree, figure, lightning exposure and typography share the same perspective, palette and light pass. Artwork is generated by code with Pillow/NumPy; it does not use AI-generated imagery or third-party footage.

## Modules

- `palette.py` — dimensions, approved shot timing and shared palette.
- `clouds.py` — continuous multi-scale storm volume, flash scattering and three rain depths.
- `environment.py` — textured skyline, stepped Art Deco landmark, wet street, shelter facade and tree.
- `lightning.py` — branched channel, progressively developing leader and upward streamer.
- `camera.py` — restrained push/pan movement.
- `captions.py` — transparent, shadowed title and speech-timed caption treatment.
- `render.py` — six-scene sequence, QC frame sheet and silent H.264 renderer.

## Local commands

```bash
python3 -m episodes.ep51_petir.visual_v3.render --qc
python3 -m episodes.ep51_petir.visual_v3.render --out build/ep51_petir_v3_silent_60fps.mp4
```

The render master is silent by design. For delivery, copy the already-approved AAC audio stream from the existing v2 MP4 without re-encoding; do not alter the VO or mix. Keep all earlier Drive versions unchanged.
